# Autobet Bot System (Restructured)

Professional Telegram Automated Betting & Signal Bot integrated with WinGo APIs.

## Project Structure
- `src/bot.js` - Main entry point containing core bot logic, Telegram handlers, API integrations, and keep-alive server.
- `package.json` - Node.js dependencies and run scripts.
- `render.yaml` - Deployment configuration for Render.

## Quick Start
```bash
npm install
npm start
```
